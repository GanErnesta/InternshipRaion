##ARSITEKTUR APLIKASI
-Frontend (Mobile Application) Bagian ini merupakan antarmuka (UI) berbasis Android yang dibangun menggunakan Jetpack Compose. Aplikasi ini digunakan oleh pengguna untuk berinteraksi dengan layanan AngkootApp, seperti 
mencari rute angkot di Malang, melihat peta terminal, serta melakukan manajemen akun (Login & Register).
-Backend Server (Firebase Service) Backend bertanggung jawab dalam mengelola logika aplikasi dan memproses autentikasi pengguna menggunakan Firebase Auth. Selain itu, bagian ini menangani 
integrasi pihak ketiga seperti Google Sign-In dan layanan pemetaan rute.
-Database (Firebase Realtime Database/Firestore) Database digunakan untuk menyimpan berbagai data yang berkaitan dengan aplikasi secara real-time, 
seperti data akun pengguna (nama, email, no telp), titik koordinat rute angkot di Malang, serta informasi lokasi terminal.
